# 🎵 Descargador de Música y Videos de YouTube

**Desarrollado por Martin Gaston Lopez**

## 🎯 ¿Qué es esto?
Es una aplicación súper fácil de usar para descargar música y videos de YouTube. No necesitas saber de programación ni tecnología - ¡solo hacer doble clic y listo!

## ✨ ¿Qué puedes descargar?
- 🎵 **Música de YouTube** (en formato MP3)
- 🎬 **Videos completos** (en formato MP4)
- � **Listas de reproducción completas**
- 🔥 **YouTube Shorts**
- 🎼 **Canciones de YouTube Music**

## 🚀 ¿Cómo empezar? (MUY FÁCIL)

### Paso 1: ¿Qué sistema tienes?

#### 🪟 **Si tienes Windows:**
1. Busca el archivo: **🚀 Iniciar YT-DLP (Windows).bat**
2. Haz **doble clic** en él
3. ¡Ya está! Se abrirá automáticamente en tu navegador

#### � **Si tienes Mac:**
1. Busca la aplicación: **🚀 Iniciar YT-DLP (macOS).app**
2. Haz **doble clic** en ella
3. ¡Ya está! Se abrirá automáticamente en tu navegador

#### 🐧 **Si tienes Linux:**
1. Busca el archivo: **🚀 Iniciar YT-DLP (Linux).sh**
2. Haz **doble clic** en él (o click derecho → "Ejecutar")
3. ¡Ya está! Se abrirá automáticamente en tu navegador

### Paso 2: ¡Usar la aplicación!
1. Se abrirá una página web automáticamente
2. Copia la URL del video o playlist de YouTube
3. Pégala en el cuadro de texto
4. Elige si quieres solo música (MP3) o video completo (MP4)
5. ¡Haz clic en "Iniciar Descarga" y listo!

## 💡 ¿Necesito instalar algo especial?

**¡NO!** La aplicación es **automática**:
- ✅ Detecta si tienes Python instalado
- ✅ Si no lo tienes, te dice cómo instalarlo fácilmente
- ✅ Instala todo lo necesario automáticamente
- ✅ No necesitas ser experto en computadoras

### Solo por si acaso - ¿Cómo instalar Python?

#### 🪟 **Windows:**
1. Ve a: **python.org**
2. Descarga la versión más reciente
3. **IMPORTANTE:** Durante la instalación, marca la casilla "Add Python to PATH"

#### 🍎 **Mac:**
- Normalmente ya viene instalado
- Si no: ve a **python.org** y descarga la versión más reciente

#### 🐧 **Linux:**
- Ubuntu/Debian: `sudo apt install python3 python3-pip`
- Fedora: `sudo dnf install python3 python3-pip`

## � ¿Dónde se guardan mis descargas?
Por defecto, todo se guarda en la carpeta **"Downloads"** de tu computadora. Desde la aplicación puedes elegir otra carpeta si quieres.

## 🆘 ¿Algo no funciona?

### 🔴 "No se encuentra Python"
**Solución:** Instala Python desde **python.org** (¡es gratis!)

### 🟡 "Error al descargar"
**Posibles causas:**
- URL incorrecta (verifica que sea de YouTube)
- Video privado o eliminado
- Conexión a internet lenta

### 🟢 "La página no se abre"
**Solución:** Espera un momento y ve manualmente a: **http://localhost:8080**

## 🎓 Para Usuarios Más Avanzados

Si sabes usar la terminal/consola, también puedes ejecutar:
- **Windows:** `python launch_universal.py`
- **Mac/Linux:** `python3 launch_universal.py`
